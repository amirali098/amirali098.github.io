# Amirali Daghyanoos — Persian Resume Website

A static RTL Persian resume designed for GitHub Pages.

## Publish on GitHub Pages
1. Create a repository named `YOUR_USERNAME.github.io`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`.

## Files
- `index.html` — Persian resume content
- `styles.css` — responsive dark/light resume design
- `script.js` — theme switch and current year
- `profile-portrait-crop.webp` — optimized circular profile portrait

The website uses the Persian **Vazirmatn** font from Google Fonts and Devicon for technology logos.
